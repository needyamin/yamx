HTTP API

Base URL is your yamx web listen address (default http://127.0.0.1:8765). All write endpoints expect Content-Type: application/json unless noted. Discover the canonical list at runtime: GET /api/routes returns groups and a flat routes array.

Security: there is no built-in API token. Treat this surface as trusted-local only; do not expose the port to the public internet without a reverse proxy and authentication.

State & project

MethodPathDescription
GET/api/statecwd, root, platform, allowDangerous, provider, model, sessionId
GET/api/infoversion, node, projectRoot, configPath, …

Configuration

MethodPathBody / notes
GET/api/configMasked config; API keys shown as placeholders
PATCH/api/configPartial YamX config merge (omit empty secrets to keep stored keys)
POST/api/config/reset{} — reset defaults
POST/api/runtime/reload{} — drop in-memory agent/config cache

Sessions (CRUD)

Session files live under ~/.yamx/sessions/. UUID in the path is the session id.

MethodPathBody / query
GET/api/sessionsList + activeSessionId
POST/api/sessions{ "title"?, "cwd"?, "activate"?: true } — 201 created; defaults activate: true
GET/api/sessions/:idOptional ?full=1 to include messages
PATCH/api/sessions/:id{ "title" }
DELETE/api/sessions/:idDeletes file; clears active id if it matched
POST/api/sessions/active{ "id": "<uuid>" } or { "id": null } to clear

Agent & tools

MethodPathBody
GET/api/toolsTool count, categories, definitions (name, description, parameters)
POST/api/command{ "command", "shell"?, "cwd"? } — shell router or agent chat
POST/api/chat{ "message" } or { "command" } — agent only

Discovery

GET/api/routes{ ok, groups[], routes[] } — grouped + flat documentation

Examples

Create session

curl -s -X POST http://127.0.0.1:8765/api/sessions \
  -H "Content-Type: application/json" \
  -d '{"title":"From API","activate":true}'

Patch config (example)

curl -s -X PATCH http://127.0.0.1:8765/api/config \
  -H "Content-Type: application/json" \
  -d '{"defaultProvider":"openai","settings":{"verboseCli":false}}'
