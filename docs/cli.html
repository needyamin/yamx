Command-line interface

Requirements

Node.js 18+.

Install

npm install -g @needyamin/yamx@latest
yamx

From repo: npm install && npm link · Ad-hoc: npx @needyamin/yamx

First run

yamx --onboard    # provider, API key, default model
yamx --diagnose   # config, keys (masked), connectivity
yamx web          # local browser UI
yamx              # REPL (sessions persist)

Core flags

FlagDescription
-p, --provider <name>openai · anthropic · gemini · kimi · grok · openrouter · ollama
-m, --model <name>Model id for the provider
-t, --temperature <n>Sampling temperature
--max-tokens <n>Generation cap
--auto-approveAuto-approve tools (use with care)
--no-streamDisable streaming output
--new-chatStart a new session thread
--resume <id>Resume saved session
--historyList saved threads
--clear-chatClear active thread
--delete-chat <id>Delete one snapshot
--onboardInteractive setup
--reset-configReset ~/.yamx/config.json defaults
--diagnoseHealth / config report

Subcommands

  • yamx config — interactive configuration editor
  • yamx web [--host 127.0.0.1] [--port 8765] [-p provider] [-m model] [--allow-dangerous] — local web UI + HTTP API

Data locations

PathPurpose
~/.yamx/config.jsonProviders, keys, settings
~/.yamx/state.jsonActive session id
~/.yamx/sessions/*.jsonChat histories
.yamx/command-intelligence.jsonProject offline command suggestions
.yamx/command-memory.jsonProject command outcomes (YAMX_HOME overrides base)

Slash commands (REPL)

Examples: /help, /exit, /clear, /compact, /stop, /pwd, /cd, /run, /model, /skills, /agents, … — use /help in the REPL for the full list.
