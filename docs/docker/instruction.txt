=========================================
YAMX WEB - FULL POWER MODE - INSTRUCTIONS
=========================================

This folder contains the Docker Compose setup to run YamX Web locally using the Google Gemma 4 E4B AI model via Ollama. 

REQUIREMENTS:
- Docker and Docker Compose installed on your system.

HOW TO START:
1. Open your terminal.
2. Navigate to this directory (c:\laragon\www\cli-agent\docs\docker).
3. Run the following command:
   docker compose up -d --build

OPTIONAL .env:
- Copy .env.example to .env in this folder to set OLLAMA_MODEL if gemma4:e4b will not download.

WHAT HAPPENS DURING STARTUP?
- Docker builds the YamX web container using your local code.
- Docker starts Ollama (latest image) and waits until it is healthy.
- ollama-init runs ollama-pull.sh: pulls OLLAMA_MODEL (default gemma4:e4b) via OLLAMA_HOST=http://ollama:11434 with retries.

IF ollama-init FAILS (exit 1):
- docker compose logs ollama-init
- If you see "unknown command sh for ollama": the ollama image uses ENTRYPOINT ollama — this repo sets entrypoint /bin/sh for ollama-init; update docker-compose.yml from the repo.
- Try OLLAMA_MODEL=qwen2.5-coder:3b in .env then docker compose down -v && docker compose up -d --build

HOW TO ACCESS THE WEB INTERFACE:
1. Once the containers are running and the model finishes downloading, open your browser.
2. Go to: http://localhost:8765

YOUR FILES:
Your host directory (c:\laragon\www\cli-agent) is mapped directly into the YamX container at /workspace. YamX can read, edit, and interact with your code in real time!

TO STOP THE SERVER:
1. Open your terminal in this directory.
2. Run: docker compose down

IF CHAT FAILS INSIDE DOCKER (wrong model, localhost, empty API errors):
- YamX now reads OPENAI_BASE_URL / DEFAULT_PROVIDER / DEFAULT_MODEL from compose after config.json.
- If an old volume still causes issues: docker compose down -v && docker compose up -d --build
