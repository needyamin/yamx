=========================================
YAMX WEB - FULL POWER MODE - INSTRUCTIONS
=========================================

This folder contains the Docker Compose setup to run YamX Web locally using Ollama.
Default model: qwen2.5-coder:0.5b (very low-memory option).
Avoid gemma4:e4b on tight RAM unless you have plenty of headroom.

REQUIREMENTS:
- Docker and Docker Compose installed.

HOW TO START:
1. Open terminal.
2. Go to this directory: C:\laragon\www\cli-agent\docs\docker
3. Copy `.env.example` to `.env` and set:
   - YAMX_WEB_USERNAME
   - YAMX_WEB_PASSWORD
4. Run:
   docker compose up -d --build

AUTO-START AFTER REBOOT:
- `ollama` and `yamx-web` use `restart: unless-stopped`.
- After first successful `docker compose up -d`, Docker usually brings them back automatically when the daemon restarts.
- Windows Docker Desktop: enable "Start Docker Desktop when you sign in".
- Windows Task Scheduler: run `startup-compose.ps1` at logon/startup.
- Linux: use `yamx-docker.service.example` + `startup-compose.sh` and enable with systemd.

OPTIONAL .env:
- Copy `.env.example` to `.env` in this folder.
- Default is `OLLAMA_MODEL=qwen2.5-coder:0.5b`.
- `YAMX_WEB_USERNAME` and `YAMX_WEB_PASSWORD` are required (HTTP Basic login).
- Provider/model bootstrap defaults are local Ollama; later changes from YamX web or CLI config persist.
- Context RAM saver defaults:
  - `YAMX_CONTEXT_BUDGET_CHARS=50000`
  - `YAMX_CONTEXT_KEEP_LAST_MESSAGES=6`
  - `YAMX_CONTEXT_ROLLOVER_MODE=summary-next-session`
- You can override retries if network is slow:
  - `OLLAMA_INIT_PULL_RETRIES=12`
  - `OLLAMA_INIT_PULL_RETRY_SECONDS=45`

WHAT HAPPENS DURING STARTUP?
- Docker builds the YamX web container.
- Docker starts Ollama and waits for health check.
- `ollama-init` runs `ollama-pull.sh` and ensures the model exists.
- Model blobs are stored in persistent volume `ollama_data`.
- If the model already exists in `ollama_data`, init skips pull, so boot/startup does not repeatedly re-download.

IF ollama-init FAILS (exit 1):
- Check logs:
  docker compose logs ollama-init
- Common reasons: disk full, timeout, TLS/network issues, wrong model tag.
- Ensure Docker has enough free disk for model files.
- If RAM is too low, choose a smaller tag in `.env`.

WEB UI:
- Open: http://localhost:8765
- Login is required (HTTP Basic auth prompt in browser).

YOUR FILES:
- Host repo `C:\laragon\www\cli-agent` is mounted into container at `/workspace`.

STOP:
- Run:
  docker compose down

RESET VOLUMES (only if needed):
- Run:
  docker compose down -v
  docker compose up -d --build

QUICK REFERENCE:
- YamX Web (host): http://localhost:8765
- Ollama API (host): http://localhost:11434
- YamX -> Ollama (inside container): http://ollama:11434/v1
- API key value in compose: `ollama` (placeholder)
- Model source of truth: `OLLAMA_MODEL` in `.env` (default qwen2.5-coder:0.5b)
- Volumes: `ollama_data` = models, `yamx_data` = /root/.yamx
