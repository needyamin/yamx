CLI reference

Requirements

Node.js 18+.

Install

npm install -g @needyamin/yamx@latest
yamx

From repo: npm install && npm link - Ad-hoc: npx @needyamin/yamx

First run

yamx --onboard    # provider, API key, default model
yamx --diagnose   # config, keys (masked), connectivity
yamx web          # local browser UI
yamx              # REPL (sessions persist)

Core flags

-m, --model <name>Model id for the provider
-t, --temperature <n>Sampling temperature
--max-tokens <n>Generation cap

--diagnoseHealth and config report

Subcommands

  • yamx config - interactive configuration editor
  • yamx web [--host 127.0.0.1] [--port 8765] [-p provider] [-m model] [--allow-dangerous] - local web UI + HTTP API

Slash commands

Examples: /help, /exit, /clear, /compact, /stop, /pwd, /cd, /run, /model, /skills, /agents. Use /help in REPL for the full list.

Web UI reference

A browser control plane served by YamX on 127.0.0.1 by default. Keep it loopback-only unless you add your own authentication.

Start

yamx web
yamx web --port 8787
yamx web --host 127.0.0.1 --port 8765
yamx web --allow-dangerous   # only if you understand tool policy risks

Open the printed URL (example: http://127.0.0.1:8765).

Layout

Shell, Settings, Sessions, Tools and API. On narrow screens the sidebar is a drawer.

Chat-like turns. Command-like input executes shell routing; non-command text routes to YamX agent with tools/session context.

General, Providers, Behavior, Model council, Subagents, Shell policy. Saves to ~/.yamx/config.json.

Create, refresh, activate, rename, delete. Uses the same session CRUD API.

Grouped API reference, raw /api/routes JSON, tool registry with schema details, and engineering readiness panel.

Static assets

  • GET / - HTML shell
  • GET /style.css - theme
  • GET /app.js - client script

HTTP API reference

Base URL is your yamx web listen address (default http://127.0.0.1:8765). Write endpoints expect Content-Type: application/json. Discover runtime route metadata via GET /api/routes.

Security: there is no built-in API token. Keep this local-only unless protected behind your own auth proxy.

State and project

MethodPathDescription
GET/api/statecwd, root, platform, allowDangerous, provider, model, sessionId
GET/api/infoversion, node, projectRoot, configPath

Configuration

MethodPathBody and notes
GET/api/configMasked config; keys shown as placeholders
PATCH/api/configPartial YamX config merge
POST/api/config/reset{} reset defaults
POST/api/runtime/reload{} clear in-memory cache

Sessions (CRUD)

MethodPathBody and query
GET/api/sessionsList + activeSessionId
POST/api/sessions{ "title"?, "cwd"?, "activate"?: true }
GET/api/sessions/:id?full=1 includes messages
PATCH/api/sessions/:id{ "title" }
DELETE/api/sessions/:idDeletes session file
POST/api/sessions/active{ "id": "<uuid>" } or { "id": null }

Agent and tools

MethodPathBody
GET/api/toolsTool count/categories/definitions
GET/api/engineering/readinessOffline readiness snapshot (?force=1 optional)
POST/api/engineering/challenge{ "suite"?, "profile"?, "force"? }
POST/api/command{ "command", "shell"?, "cwd"? }
POST/api/chat{ "message" } or { "command" }

Discovery

GET/api/routes{ ok, groups[], routes[] }

Examples

Create session

curl -s -X POST http://127.0.0.1:8765/api/sessions \
  -H "Content-Type: application/json" \
  -d '{"title":"From API","activate":true}'

Patch config

curl -s -X PATCH http://127.0.0.1:8765/api/config \
  -H "Content-Type: application/json" \
  -d '{"defaultProvider":"openai","settings":{"verboseCli":false}}'
