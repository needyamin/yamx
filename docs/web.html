Local web UI

A browser control plane served by YamX on 127.0.0.1 by default. Not a hosted SaaS — keep it on loopback unless you add your own auth.

Start

yamx web
yamx web --port 8787
yamx web --host 127.0.0.1 --port 8765
yamx web --allow-dangerous   # only if you understand tool policy risks

Open the printed URL (e.g. http://127.0.0.1:8765).

Layout

Shell, Settings, Sessions, Tools & API. On narrow screens the sidebar is a drawer (hamburger, backdrop, Esc to close).

Chat-style turns: your message appears immediately; a working indicator runs until the server responds. Command-like input can execute as shell; other text routes to the YamX agent (tools, sessions, project context). The shell lives in a bounded card (not full-screen edge-to-edge).

Section pill tabs: General, Providers, Behavior, Model council, Subagents, Shell policy. Edits merge into ~/.yamx/config.json (API keys masked in the browser). Buttons: save, reload agent cache, reset to defaults.

New session, Refresh, per-row Use (set active), Rename, Delete. Matches the HTTP session CRUD API. Changing the active session invalidates the web agent cache for the next message.

Grouped API reference table (method badges, path, body hint, notes). Click a row to copy the path. Collapsible raw GET /api/routes JSON. Tool list with search and expandable JSON Schema per tool.

Static assets (when server is running)

  • GET / — HTML shell
  • GET /style.css — theme
  • GET /app.js — client script
